# javascript-calculator-precourse

## 구현할 기능 목록

### 1️⃣ 입력값을 구분자를 기준으로 파싱한다. (파싱)

> 책임: 입력 문자열에서 구분자를 기준으로 파싱한 배열을 생성한다.

- 빈 문자열이 입력되면 0을 반환하고 종료한다.
- 커스텀 구분자가 지정된 경우 해당 구분자를 추출한다.
- 커스텀 구분자가 없으면 기본 구분자(쉼표, 콜론)를 사용한다.
- 구분자를 기준으로 문자열을 나누어 파싱한 배열을 생성한다.

### 2️⃣ 분리된 입력 문자열이 계산 가능한지 확인한다. (검증)

> 책임: 파싱된 입력 문자열 배열에서 계산할 수 없는 값이 있는지 확인한다.

- 음수가 포함되어 있는지 확인한다.
- 숫자로 변환할 수 없는 값이 포함되어 있는지 확인한다.
- 유효성 검사에 실패하면 [ERROR]로 시작하는 메시지와 함께 에러를 발생시킨다.

### 3️⃣ 숫자들의 합을 계산한다. (계산)

> 책임: 검증과 파싱을 통과한 숫자 문자열 배열을 실제 숫자로 변환하여 합계를 반환한다.

- 문자열 배열을 숫자 배열로 변환한다.
- 변환된 숫자 배열의 모든 요소를 더해 합을 계산한다.
